# ALEPH T01 — 나를 소개하는 한 페이지

## 프로젝트명
Lee Seul gi — Portfolio

## 프로젝트 목적
음악에서 디자인을 거쳐 개발까지 이어진 경험을 연결해, 채용 담당자·협업자에게
근거와 함께 보여주는 한 페이지를 만든다.

## 대상 사용자

- 함께 프로젝트를 진행할 협업자
- 작업 방식과 경험이 궁금한 사람

## 화면 구조

구성된 1페이지 구조다. Hero는 [눈썹 제목 + 이름] | 세로 구분선 | [대표 문장 +
설명 + 근거 요약]의 가로형 마스트헤드로 얇게 두고, 그 아래 폴더를 한 줄로
나열해 스크롤 없이 첫 화면에서 이름·대표 문장·근거 요약·폴더·Contact가 모두
보인다. 900px 이하에서는 구분선이 가로선으로 바뀌며 세로로 쌓인다. 각 폴더를
열면 모달로 상세 내용이 뜬다.

- **Hero**: 이름(Lee Seul gi), 타이틀(Portfolio), 대표 문장, 설명, 클릭 가능한 근거

- **INK ROOM 폴더**: 직접 만든 웹 게임 "잉크의 방"으로 이동하는 외부 링크

- **About Me 모달**: 페이지 목적 한 문장 + 강점 3개(상황·행동·결과 + 근거 폴더

## 대상과 공개 범위
이 페이지는 채용 담당자·협업자에게 무엇을 할 수 있는지 근거와 함께 보여주기
위해 만들었다. 이름과 학력·경력·프로젝트를 검증 가능하도록 실제 정보 그대로
공개한다.

**공개하는 것**
- 이름과 학력·경력
- 실제 프로젝트 결과물과 소스
- 기술 스택과 사용 도구
- 자격·이수 내역
- 공개 연락 채널

**공개하지 않는 것**
- 생년월일 등 개인 식별 정보
- 전화번호·자택 주소
- 희망 연봉
- 협업자의 개인 정보
- 자격증·성적증명서 등 민감 문서 원본

## 디자인 방향
어두운 남색 그라데이션 배경 위에 글래스모피즘(반투명 + blur) 카드를 올린
디자인. 데스크톱 mac 폴더 아이콘 메타포를 사용해 각 주제를 폴더로, 상세
내용을 모달로 구성했다.
- 팔레트: 딥 네이비 그라데이션(#13233f → #628cb4), 흰색·회색 텍스트
- 타이포: 제목과 본문 모두 Pretendard 중심으로 구성하고, CDN 폰트가 로드되지
  않으면 시스템 한글 글꼴로 대체한다. 별도 빌드는 없다.
- 버튼·링크·상태 배지는 흰색 테두리와 글래스 pill 스타일로 통일한다.
- 명암비: 모달 본문과 어두운 영역의 주요 텍스트는 기준을 충족하지만, 밝은
  그라데이션 위 폴더 라벨과 보조 문구 일부는 4.5:1 미만으로 확인되어 조정이
  필요하다. 자세한 값은 아래 검사 결과에 기록한다.

## 구현한 상호작용
1. **첫 화면 근거 요약 → 모달**: 연주 경력·웹디자인 실무 3곳·개발 프로젝트
   5개를 각각 클릭하거나 키보드로 실행하면 관련 모달이 열린다.
2. **폴더 → 모달**: 폴더를 클릭(또는 Tab 이동 후 Enter/Space)하면 같은 모달
   컴포넌트에 내용만 바뀌어 열린다. 바깥(백드롭) 클릭, X 버튼, Esc 키로 닫히고
   닫으면 포커스가 원래 폴더로 돌아온다. 다른 모달을 새로 열면 이전 스크롤
   위치를 이어받지 않고 항상 상단에서 시작한다.
3. **모달 내 근거 이동 버튼**: About Me의 각 강점 아래 "근거 보기" 버튼을
   누르면 모달을 닫지 않고 내용만 해당 폴더로 바뀌며, 포커스가 새 제목으로
   이동해 스크린리더에도 변경이 전달된다
4. **움직임 줄이기 토글**: 헤더의 토글로 배경 애니메이션, About Me 폴더의
   부유 효과와 모달 전환 효과를
   끌 수 있고 `localStorage`에 저장된다. `prefers-reduced-motion` 시스템 설정도
   함께 지원한다
5. **INK ROOM 폴더 → 게임 새 창**: 폴더를 클릭하거나 Tab 이동 후 Enter를 누르면
   게임 페이지가 새 창으로 열린다. `aria-label`에 "(새 창)"을 표기했다

## 접근성 대응 내용
- 본문 바로가기(skip link)
- 제목 단계 `h1 → h2 → h3 → h4` 순서 유지, 모달마다 검사 스크립트로 확인
- 키보드 포커스 표시(`:focus-visible`), 네이티브 `<dialog>`로 포커스 트랩
- 링크 텍스트만으로 목적 파악 가능, 반복되는 프로젝트 링크는 `aria-label`에
  프로젝트명 포함, 새 창 링크에 "(새 창)" 표기 + `rel="noopener noreferrer"`
- 색상만으로 구분하지 않음(공개 ＋ / 비공개 × 기호 + 텍스트 병기, 상태 배지에
  문구 포함)
- 본문 대비 4.5:1 이상, 포인트색 3:1 이상 목표 팔레트(위 명암비 참고)

## 짧은 확인 방법 4줄
1. 위치: 첫 화면 이름 아래 한 줄로 놓인 폴더 중 INK ROOM을 제외한 4개(About

2. 행동: 폴더를 클릭하거나 Tab 으로 이동한 뒤 Enter 또는 Space 를 누릅니다.
3. 통과 모습: 화면 가운데에 모달이 뜨고 바깥이 어두워지며, 해당 주제의
   실제 내용(경력·프로젝트·근거 링크)이 보입니다.
4. 안 될 때 모습: 눌러도 모달이 뜨지 않거나, 키보드로 실행되지 않거나, 모달이
   메인 화면과 다른 톤으로 어색하게 보입니다.

## AI와 본인의 판단 3줄
1. AI에게 맡긴 일: 시맨틱 HTML/CSS/JS 구현, 모달 컴포넌트화(`<template>` +
   공용 `<dialog>`), 배경 애니메이션과 글래스모피즘 스타일 초안, 첫 화면 근거
   요약 버튼·모달 스크롤 초기화·파비콘 조정, 링크 상태·명암비·가로 넘침·콘솔
   오류 검사와 README 정리.
2. 학생이 직접 판단한 일: 공개/비공개 정보 범위와 이름 표기 방식,
   About Me·Music·Dev·Web Design 각 섹션에 넣을 실제 이력과 프로젝트 선택,
   이력서 2종과 자격 인증 캡처를 근거 자료로 제공, 디자인 톤(남색 글래스모피즘)
   방향 지정.
3. AI 제안을 따르지 않은 일: 강점 항목을 모달 하나에 몰아 설명하자는 초안 대신
   상황·행동·결과 뒤에 해당 근거 폴더로 바로 가는 버튼을 각각 붙이는 구조를
   요청해 반영했습니다. 소스가 비공개인 Ssuk Ssuk은 공개 저장소 링크를 억지로
   추가하지 않고 결과물 링크와 "소스 저장소 비공개" 문구만 표시했습니다.

## 검사에서 발견한 실제 결함과 수정 전·후 (T01-C17)

### 결함 1 — 첫 화면에 확인 가능한 근거가 없음 (화면·내용 검사)
- 수정 전: 소개 문장과 활동 폴더만 있고 구체적인 결과가 첫 화면에 없어,
  1366×768과 1920×1080에서 소개·활동·근거가 함께 보여야 하는 기준을 충족하지
  못했다.
- 수정 후: `연주 경력`, `웹디자인 실무 3곳`, `개발 프로젝트 5개`를 근거 요약으로
  추가했다. 각 항목은 버튼이며 관련 Music·Web Design·Dev / Projects 모달을
  마우스와 키보드로 연다. 로컬 두 기준 해상도에서 스크롤 전 노출을 확인했다.

### 결함 2 — About Me 폴더의 움직임과 글자 정렬이 함께 어색해 보임 (화면 검사)
- 수정 전: About Me 폴더의 부유 효과 때문에 아래 라벨까지 다른 폴더보다 위로
  움직이는 것처럼 보였고, 애니메이션을 전부 제거하면 원래 의도한 강조도
  사라졌다.
- 수정 후: 고정 크기 아이콘 프레임에만 `translateY` 애니메이션을 적용했다.
  폴더 이미지는 위아래로 움직이지만 `ABOUT ME` 라벨은 `MUSIC` 라벨과 같은
  기준선에 유지된다. 움직임 줄이기 설정에서는 이 효과도 정지한다.

### 결함 3 — 다른 모달을 열 때 이전 스크롤 위치가 남음 (상호작용 검사)
- 수정 전: 긴 모달을 아래로 스크롤한 뒤 닫고 다른 모달을 열면 이전 스크롤
  위치가 이어져 새 내용의 중간부터 보이는 경우가 있었다.
- 수정 후: 콘텐츠 교체 직후와 `dialog.showModal()` 직후에 모달·패널·콘텐츠의
  스크롤을 모두 초기화하고, 다음 렌더링 프레임에서 한 번 더 확인하도록 했다.
  About Me를 785px 스크롤한 뒤 Music을 열어 `scrollTop`이 0인 것을 확인했다.

### 결함 4 — 한국어 문장이 의미 중간에서 줄바꿈됨 (화면 검사)
- 수정 전: 소개 문장이 `개발을 / 배우고 있습니다`처럼 문장 성분 중간에서
  갈라졌고, 근거 요약 버튼의 글자도 좁은 화면에서 개별 단어가 끊길 수 있었다.
- 수정 후: 소개 문장을 의미 단위의 블록으로 나누고 `word-break: keep-all`과
  `overflow-wrap`을 적용했다. 근거 요약은 버튼 내부가 아닌 항목 사이에서만
  줄바꿈되도록 했다.
