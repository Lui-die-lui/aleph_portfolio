# Task 08 — 3분 체크

## 1. 어디로 가나요

배포 URL(예: `https://seulgi-portfolio-henna.vercel.app/`) 접속 → 메인 화면 폴더 그리드에서
열쇠 아이콘("PRIVATE ARCHIVE") 클릭.

## 2. 세 단계 안에 무엇을 하나요

1. 열쇠 아이콘 클릭 → "패스키로 보호된 공간" 모달이 뜬다.
2. "패스키로 열기" 클릭 → 브라우저/OS가 패스키(지문·얼굴·PIN·보안키) 인증 창을 띄운다.
3. 등록된 패스키로 인증 → 모달 안에서 바로 비공개 기록 목록이 보인다.

## 3. 무엇이 보이면 통과인가요

- 비밀번호나 이메일 입력창이 한 번도 뜨지 않는다.
- 인증 성공 직후 "OO님, 환영합니다." 문구와 함께 비공개 기록 카드(제목/카테고리/내용/수정일)가 보인다.
- "새 기록 추가", "패스키 관리", "로그아웃" 버튼이 모두 동작한다(추가/수정/삭제 후 "저장했습니다" 류 메시지가 잠깐 떴다가 사라짐).

## 4. 안 될 때는 무엇이 보이나요

- 이 기기에 등록된 패스키가 없으면: 인증 창 자체가 뜨지 않거나, 뜨더라도 선택할 패스키가 없다고 나온다 — 이건 정상 동작이다(이 기기로는 원래 못 들어가야 함).
- 인증을 취소하거나 시간이 초과되면: 모달에 "패스키 로그인을 취소했거나 시간이 초과되었습니다." 빨간 문구가 뜨고, 새로 "패스키로 열기"를 눌러 다시 시도할 수 있다.
- 그 외 서버 문제(예: 환경변수 미설정)일 경우: "로그인을 시작할 수 없습니다. 잠시 후 다시 시도해주세요." 문구가 뜬다 — 이 경우는 배포 환경변수(`T08_RP_ID`, `T08_EXPECTED_ORIGIN`, Supabase 접속정보)를 확인해야 한다.
